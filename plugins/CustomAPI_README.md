# CustomAPI 插件使用指南

## 🚀 功能简介

CustomAPI 插件是一个强大的自定义API调用工具，允许用户通过简单的配置创建自己的API调用功能。插件支持丰富的变量系统、多种HTTP方法、错误处理机制和直观的Web UI配置界面。

## ✨ 主要特性

### 🎯 核心功能
- 🔧 **完全自定义**：用户可以自定义API名称、触发指令、请求参数等
- 🌐 **Web UI配置**：提供美观直观的网页配置界面
- 📝 **丰富变量系统**：支持70+种变量类型，满足各种需求
- 🧪 **实时测试功能**：内置变量测试工具，实时预览效果

### 🛠️ 技术特性
- 🔄 **多HTTP方法**：支持GET、POST、PUT、DELETE、PATCH、HEAD
- ⚡ **智能重试**：支持自动重试和指数退避策略
- 🛡️ **错误处理**：完善的错误处理和自定义错误消息
- 🔒 **安全配置**：SSL验证、超时设置、状态码检查

## 📋 快速开始

### 1. 启动Web UI
发送指令：`-打开自定义API配置`（需要管理员权限）

### 2. 添加API
1. 点击"添加API"按钮
2. 填写API名称和触发指令
3. 配置API参数（URL、方法、请求头等）
4. 设置响应模板
5. 点击"保存配置"

### 3. 测试API
使用配置的触发指令测试API功能

## 🎛️ 变量系统详解

### 📊 变量分类总览

#### 👤 基础用户变量
- `【用户消息】` - 用户发送的消息
- `【原始消息】` - 包含前缀的原始消息
- `【发送者QQ】` - 发送者QQ号
- `【发送者昵称】` - 发送者昵称
- `【发送人头像】` - 发送者QQ头像(CQ码)
- `【发送人头像链接】` - 发送者头像URL
- `【机器人QQ】` - 机器人QQ号
- `【机器人头像】` - 机器人头像(CQ码)
- `【机器人头像链接】` - 机器人头像URL

#### 👥 群组信息变量
- `【群号】` - 当前群号
- `【群名称】` - 群组名称
- `【群人数】` - 当前群人数
- `【群最大人数】` - 群最大人数限制

#### ⏰ 时间变量
- `【当前时间】` - 完整日期时间 (2024-01-15 14:30:25)
- `【年】` - 当前年份 (2024)
- `【月】` - 当前月份，补零 (01)
- `【日】` - 当前日期，补零 (15)
- `【时】` `【分】` `【秒】` - 时分秒，补零
- `【时分秒】` - HH:MM:SS格式
- `【星期】` - 星期几(中文) (一)
- `【星期数字】` - 星期几(1-7)
- `【时间戳】` - Unix时间戳
- `【毫秒时间戳】` - 毫秒时间戳
- `【ISO时间】` - ISO格式时间

#### 💻 系统信息变量
- `【系统名称】` - 操作系统名称 (Windows)
- `【系统版本】` - 系统版本
- `【处理器】` - CPU信息
- `【CPU使用率】` - CPU使用百分比 (15.6%)
- `【内存使用率】` - 内存使用百分比 (68.2%)
- `【可用内存】` - 可用内存(GB) (8.5GB)
- `【总内存】` - 总内存(GB) (16.0GB)
- `【磁盘使用率】` - 磁盘使用百分比
- `【可用磁盘】` - 可用磁盘空间(GB)
- `【总磁盘】` - 总磁盘空间(GB)

#### 🎲 随机变量
- `【随机数字】` - 1-100随机数
- `【随机数字1-10】` - 1-10随机数  
- `【随机数字1-1000】` - 1-1000随机数
- `【随机UUID】` - UUID字符串
- `【随机字符串】` - 8位随机字符串

#### ✏️ 消息处理变量
- `【消息长度】` - 消息字符长度
- `【消息字数】` - 消息字数(不含空格)
- `【消息单词数】` - 英文单词数量
- `【用户消息大写】` - 消息转大写
- `【用户消息小写】` - 消息转小写
- `【用户消息首字母大写】` - 首字母大写
- `【用户消息反转】` - 消息反转
- `【跨取文本#n#m】` - 截取第n到m个字符

#### 📄 格式化变量
- `【换行】` - 换行符 (\n)
- `【制表符】` - Tab制表符 (\t)
- `【空格】` - 单个空格
- `【at】` - @发送消息的用户
- `【at所有人】` - @全体成员

#### 🔗 API响应变量
- `【纯文本】` - API返回的文本
- `【纯图片】` - API返回图片显示
- `【图片链接】` - 原始图片URL
- `【json文本#路径】` - JSON中的文本值
- `【json图片#路径】` - JSON中的图片

#### ⚡ 高级功能变量
- `【条件#条件表达式#真值#假值】` - 条件判断
- `【计算#数学表达式】` - 数学计算

### 🧮 高级变量详解

#### 条件判断变量
格式：`【条件#条件表达式#真值#假值】`

支持的条件操作符：
- `=` - 等于
- `!=` - 不等于  
- `>` - 大于
- `<` - 小于

示例：
```
【条件#【用户消息】=你好#欢迎！#再见！】
【条件#【消息长度】>10#消息太长了#消息长度正常】
【条件#【发送者QQ】=123456789#这是管理员#普通用户】
```

#### 计算变量
格式：`【计算#数学表达式】`

支持的运算：
- 基本运算：`+` `-` `*` `/`
- 括号：`(` `)`
- 数字和小数

示例：
```
【计算#1+1】  // 结果：2
【计算#【消息长度】*2】  // 消息长度的两倍
【计算#(【随机数字】+10)/2】  // 随机数加10后除以2
```

#### JSON路径变量
格式：`【json文本#路径】` 或 `【json图片#路径】`

支持：
- 对象属性：`data.message`
- 数组索引：`data.0.name`
- 嵌套路径：`response.data.items.0.title`

示例：
```json
// API返回：{"data": {"message": "Hello", "user": {"name": "张三"}}}
【json文本#data.message】  // 结果：Hello
【json文本#data.user.name】  // 结果：张三
```

## 🔧 配置选项详解

### 基础配置
- **API名称**：API的显示名称
- **触发指令**：触发API调用的指令
- **启用状态**：是否启用此API
- **使用指令前缀**：是否需要机器人前缀（如`-`）
- **读取指令后消息**：是否只读取指令后面的内容

### HTTP配置  
- **请求方法**：GET、POST、PUT、DELETE、PATCH、HEAD
- **API URL**：目标API地址（支持变量）
- **请求头**：HTTP请求头（JSON格式）
- **请求体模板**：请求体内容（支持变量）

### 高级配置
- **超时时间**：请求超时时间（秒）
- **最大重试次数**：失败后的重试次数
- **冷却时间**：两次调用之间的间隔（秒）
- **错误消息模板**：失败时显示的错误信息
- **JSON编码**：是否将请求体编码为JSON
- **跟随重定向**：是否自动跟随HTTP重定向
- **SSL验证**：是否验证HTTPS证书

## 📚 使用示例

### 示例1：天气查询API
```json
{
  "name": "天气查询",
  "trigger": "天气",
  "url": "https://api.weather.com/v1/current",
  "method": "GET",
  "body_template": {
    "city": "【用户消息】",
    "key": "your_api_key"
  },
  "response_template": "【发送者昵称】，【用户消息】的天气：\n温度：【json文本#temp】°C\n描述：【json文本#desc】\n查询时间：【当前时间】"
}
```

### 示例2：翻译API
```json  
{
  "name": "翻译助手",
  "trigger": "翻译",
  "url": "https://api.translate.com/v2/translate",
  "method": "POST",
  "headers": {
    "Authorization": "Bearer your_token",
    "Content-Type": "application/json"
  },
  "body_template": {
    "text": "【用户消息】",
    "source": "auto", 
    "target": "zh"
  },
  "response_template": "翻译结果：【json文本#translation】\n原文：【用户消息】\n翻译时间：【当前时间】"
}
```

### 示例3：条件回复API

## 🐛 故障排除

### 常见问题

**Q: API调用失败怎么办？**
A: 检查以下内容：
- API URL是否正确
- 网络连接是否正常
- API密钥或认证信息是否有效
- 请求头和请求体格式是否正确

**Q: 变量没有被替换？** 
A: 确认：
- 变量名称拼写是否正确（注意中文标点）
- 变量是否在当前上下文中可用
- 是否有语法错误

**Q: JSON路径变量获取失败？**
A: 检查：
- API是否返回有效的JSON
- JSON路径是否正确
- 数组索引是否越界

**Q: Web UI无法打开？**
A: 尝试：
- 检查端口是否被占用
- 重启机器人程序
- 检查防火墙设置

### 调试技巧
1. 使用变量测试器验证变量效果
2. 查看机器人日志了解详细错误信息
3. 先用简单的API测试基础功能
4. 逐步添加复杂的变量和逻辑

## 🚀 高级用法

1. 第一个API获取数据
2. 将结果传递给第二个API

### 动态配置

- 根据用户权限返回不同内容
- 实现个性化的API响应

### 性能优化
- 设置合理的超时时间
- 使用冷却时间限制调用频率
- 启用重试机制提高成功率
