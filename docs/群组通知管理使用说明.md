# 群组通知管理功能使用说明

## 功能概述

小依QQ机器人现在支持为每个群组独立配置入群和退群提示功能，包括：

- ✅ 独立控制每个群的入群欢迎开关
- ✅ 独立控制每个群的退群提示开关
- ✅ 为每个群设置自定义的入群欢迎消息
- ✅ 为每个群设置自定义的退群提示消息
- ✅ 自动创建和管理配置文件
- ✅ 支持变量替换（退群消息中的 `{user_nick}` 和 `{bot_name}`）

## 管理员命令

### 查看群组通知状态
```
-群组通知
```
显示当前群组的入群和退群提示配置状态。

### 控制入群欢迎功能
```
-入群欢迎 开    # 启用当前群的入群欢迎功能
-入群欢迎 关    # 禁用当前群的入群欢迎功能
```

### 控制退群提示功能
```
-退群提示 开    # 启用当前群的退群提示功能
-退群提示 关    # 禁用当前群的退群提示功能
```

### 设置自定义消息
```
-设置入群消息 欢迎新成员！🎉    # 设置自定义入群欢迎消息
-设置退群消息 {user_nick}离开了群聊，再见！👋    # 设置自定义退群提示消息
```

## 自定义消息变量

在自定义退群消息中，你可以使用以下变量：

- `{user_nick}` - 离开用户的昵称（如果无法获取则显示"有人又"）
- `{bot_name}` - 机器人名称

例如：`{user_nick}离开了{bot_name}的大家庭，我们会想念TA的！`

## 配置文件

- 配置文件自动保存在 `data/group_notice/` 目录下
- 每个群组一个配置文件，文件名为 `{群号}.json`
- 文件包含入群退群开关、自定义消息和时间戳信息

## 默认行为

- 新群组默认启用入群欢迎和退群提示
- 如果没有设置自定义消息，会使用机器人的默认消息
- 配置文件会在首次使用时自动创建

## 权限要求

所有群组通知管理命令需要管理员权限（Manage_User、Super_User 或 ROOT_User）。

## 示例使用流程

1. 管理员发送 `-群组通知` 查看当前状态
2. 如需关闭入群欢迎：发送 `-入群欢迎 关`
3. 如需设置自定义消息：发送 `-设置入群消息 欢迎加入我们的大家庭！`
4. 再次发送 `-群组通知` 确认配置

## 注意事项

- 每个群组的配置是独立的，互不影响
- 关闭功能后，对应的入群/退群事件将不会触发任何消息
- 自定义消息支持表情符号和特殊字符
- 配置修改会立即生效，无需重启机器人
