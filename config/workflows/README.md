# 工作流系统使用指南

## 概述

工作流系统是小依机器人的新功能，允许用户通过可视化界面创建、管理和执行自动化工作流。工作流可以根据特定条件自动触发，执行一系列预定义的操作。

## 主要特性

### 1. 可视化管理界面
- 直观的工作流列表和详情视图
- 拖拽式步骤排序
- 实时预览和测试功能

### 2. 灵活的路由规则
支持多种触发条件：
- **关键词匹配**: 消息包含特定关键词时触发
- **正则表达式**: 使用正则表达式匹配复杂模式
- **用户权限**: 根据用户权限级别触发
- **群组ID**: 特定群组中的消息触发
- **用户ID**: 特定用户的消息触发
- **时间条件**: 特定时间点触发
- **自定义条件**: 自定义条件函数

### 3. 丰富的执行步骤
- **调用插件**: 执行现有插件功能
- **条件判断**: 基于变量或上下文进行分支处理
- **发送消息**: 向用户或群组发送消息
- **设置变量**: 设置和管理工作流变量
- **延迟执行**: 添加时间延迟
- **停止工作流**: 中断工作流执行

## 使用方法

### 1. 打开工作流管理界面

在小依配置助手中，点击"工作流管理"选项卡进入工作流管理界面。

### 2. 创建新工作流

1. 点击"新建"按钮
2. 输入工作流名称和描述
3. 设置工作流的启用状态

### 3. 配置路由规则

在"路由规则"标签页中：
1. 点击"添加路由"按钮
2. 选择路由类型（关键词、正则表达式等）
3. 输入匹配条件
4. 设置优先级（数字越大优先级越高）
5. 保存路由规则

### 4. 添加执行步骤

在"执行步骤"标签页中：
1. 点击"添加步骤"按钮
2. 选择步骤类型
3. 配置步骤参数
4. 使用"上移"/"下移"按钮调整步骤顺序

### 5. 测试工作流

在"测试运行"标签页中：
1. 输入测试消息
2. 点击"开始测试"
3. 查看测试结果和执行日志

## 配置示例

### 示例1: 自动欢迎新成员

```json
{
  "name": "自动欢迎新成员",
  "description": "当检测到欢迎关键词时发送欢迎消息",
  "routes": [
    {
      "name": "欢迎检测",
      "rule_type": "keyword",
      "condition": "欢迎",
      "priority": 100
    }
  ],
  "steps": [
    {
      "name": "发送欢迎消息",
      "type": "message",
      "config": {
        "message": "欢迎 ${user_name} 加入我们的大家庭！",
        "reply": false
      }
    }
  ]
}
```

### 示例2: 管理员权限检查

```json
{
  "name": "管理员功能",
  "description": "只有管理员才能使用的功能",
  "routes": [
    {
      "name": "管理员权限检查",
      "rule_type": "user_permission",
      "condition": "ADMIN",
      "priority": 200
    }
  ],
  "steps": [
    {
      "name": "权限验证",
      "type": "condition",
      "config": {
        "condition": "'ADMIN' in ${user_permissions}",
        "true_steps": ["admin_action"],
        "false_steps": ["deny_action"]
      }
    },
    {
      "name": "执行管理操作",
      "type": "plugin",
      "config": {
        "plugin_name": "AdminTools",
        "parameters": {}
      }
    }
  ]
}
```

## 变量系统

工作流支持变量系统，可以在步骤间传递数据：

### 内置变量
- `${message}`: 触发消息内容
- `${user_id}`: 发送者QQ号
- `${user_name}`: 发送者昵称
- `${group_id}`: 群组ID
- `${user_permissions}`: 用户权限列表

### 自定义变量
- 使用"设置变量"步骤创建自定义变量
- 在消息或条件中使用 `${变量名}` 引用变量

## 高级功能

### 条件分支
使用条件判断步骤可以创建复杂的分支逻辑：
```
condition: ${user_id} == '123456'
true_steps: ['step_for_specific_user']
false_steps: ['step_for_others']
```

### 插件集成
工作流可以调用现有的简儿插件：
- 自动检测插件参数
- 支持参数映射
- 可以保存插件执行结果

### 错误处理
- 自动记录执行日志
- 异常时停止工作流
- 支持调试模式

## 注意事项

1. **性能考虑**: 避免创建过于复杂的工作流，建议单个工作流步骤数不超过20个

## 故障排除

### 常见问题

1. **工作流不触发**
   - 检查路由规则是否正确配置
   - 确认工作流已启用
   - 查看执行日志

2. **步骤执行失败**
   - 检查步骤配置参数
   - 确认插件名称正确
   - 查看变量是否正确设置

3. **变量无法识别**
   - 确认变量名拼写正确
   - 检查变量作用域
   - 使用测试功能验证

如有其他问题，请查看系统日志或联系开发者。
