# 变量说明部分 - 大幅增强的变量系统

可用变量说明

📝 基础用户变量 ▼

  • 【用户消息】 - 用户发送的消息
  • 【原始消息】 - 包含前缀的原始消息
  • 【发送者QQ】 - 发送者QQ号
  • 【发送者昵称】 - 发送者昵称
  • 【发送人头像】 - 发送者QQ头像(CQ码)
  • 【发送人头像链接】 - 发送者头像URL
  • 【机器人QQ】 - 机器人QQ号
  • 【机器人头像】 - 机器人头像(CQ码)
  • 【机器人头像链接】 - 机器人头像URL

👥 群组信息变量 ▼

  • 【群号】 - 当前群号
  • 【群名称】 - 群组名称
  • 【群人数】 - 当前群人数
  • 【群最大人数】 - 群最大人数限制

⏰ 时间变量 ▼

  • 【当前时间】 - 完整日期时间
  • 【年】 - 当前年份
  • 【月】 - 当前月份(补零)
  • 【日】 - 当前日期(补零)
  • 【时】【分】【秒】 - 时分秒(补零)
  • 【时分秒】 - HH:MM:SS格式
  • 【星期】 - 星期几(中文)
  • 【星期数字】 - 星期几(1-7)
  • 【时间戳】 - Unix时间戳
  • 【毫秒时间戳】 - 毫秒时间戳
  • 【ISO时间】 - ISO格式时间

💻 系统信息变量 ▼

  • 【系统名称】 - 操作系统名称
  • 【系统版本】 - 系统版本
  • 【处理器】 - CPU信息
  • 【CPU使用率】 - CPU使用百分比
  • 【内存使用率】 - 内存使用百分比
  • 【可用内存】 - 可用内存(GB)
  • 【总内存】 - 总内存(GB)
  • 【磁盘使用率】 - 磁盘使用百分比
  • 【可用磁盘】 - 可用磁盘空间(GB)
  • 【总磁盘】 - 总磁盘空间(GB)

🎲 随机变量 ▼

  • 【随机数字】 - 1-100随机数
  • 【随机数字1-10】 - 1-10随机数
  • 【随机数字1-1000】 - 1-1000随机数
  • 【随机UUID】 - UUID字符串
  • 【随机字符串】 - 8位随机字符串

✏️ 消息处理变量 ▼

  • 【消息长度】 - 消息字符长度
  • 【消息字数】 - 消息字数(不含空格)
  • 【消息单词数】 - 英文单词数量
  • 【用户消息大写】 - 消息转大写
  • 【用户消息小写】 - 消息转小写
  • 【用户消息首字母大写】 - 首字母大写
  • 【用户消息反转】 - 消息反转
  • 【跨取文本#n#m】 - 截取第n到m个字符

📋 格式化变量 ▼

  • 【换行】 - 换行符
  • 【制表符】 - Tab制表符
  • 【空格】 - 单个空格
  • 【at】 - @发送消息的用户
  • 【at所有人】 - @全体成员

🔌 API响应变量 ▼

  • 【纯文本】 - API返回的文本
  • 【纯图片】 - API返回图片显示
  • 【图片链接】 - 原始图片URL
  • 【json文本#路径】 - JSON中的文本值
  • 【json图片#路径】 - JSON中的图片

⚡ 高级功能变量 ▼

  • 【条件#条件表达式#真值#假值】 - 条件判断
  • 【计算#数学表达式】 - 数学计算
  • 条件表达式支持: =, !=, >, <
  • 计算支持: +, -, *, /, (), 数字
